# Art provenance and credits

All shipped MVP art, animation, VFX, UI shapes, materials, and typography layout are original procedural work made
inside this repository from Unity primitive meshes and the Unity built-in `LegacyRuntime.ttf` font. No third-party
models, textures, animations, sound recordings, fonts, or marketplace assets are included.

Unity primitive meshes and built-in runtime resources are used under the Unity Editor Software Terms that apply to
the project. Project-authored source is covered by the repository license.

The style is intentionally bloodless: hits use squash-and-stretch, a pastel comic burst, and `SQUISH!`; deposits use
green `YUM!` bursts; the swatter is foam-like; victory uses a gold `TA-DA!` burst. No corpse, wound, blood, or realistic
injury assets exist in the shipped content.
