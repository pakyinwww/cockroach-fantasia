# Cockroach Fantasia

A cute, comedic asymmetric kitchen heist for Windows PC, built with Unity 6.3 LTS.

Play online with four friends through a private room code, or play fully offline
as either the Human or a Cockroach while three bots fill the remaining roles.
Both modes use the same four-minute Kitchen match, food-carrying rules, harmless
swatter knockouts, results, and rematch flow.

## Single-player

From the main menu, choose **SOLO: HUMAN** or **SOLO: COCKROACH**. Solo play starts
a local Netcode host and does not require Unity Services, a room code, Relay, or
an internet connection. Use WASD and the mouse; Cockroaches press E to pick up or
drop food, while the Human clicks the left mouse button to swing the swatter.
